# 📋 <프로젝트명> 스크래치보드 (사이클 큐)

> **에이전트 시작 지시 (고정)**
> 1. 아래 **사이클 큐에서 미완료 사이클 1개만** 진행한다. 큐 너머를 미리 구현하지 않는다.
> 2. 사이클 완료 = 확인 문장이 실측으로 참 + 이 문서의 체크박스 갱신 + 커밋.
> 3. 완료 후 사용자에게 **`/clear` 후 재시작**을 안내하고 종료한다.
> 4. "작업 지시 메모"에 새 지시가 있으면 먼저 1사이클 판정(`.omp/rules/harness-cycle_definition.md`)을
>    하고, 다사이클이면 구현 전에 분할안(사이클별 확인 문장 포함)을 큐에 추가 제안한다.
