## 1. 한 줄 원칙

무엇을: 이 프로덕트의 화면이 지켜야 할 인상 한 줄. 왜: 개별 규칙이 충돌할 때 이 한 줄로 판정한다.

예시: "정보 밀도가 높아도 읽는 순서가 한눈에 보이는 화면. 장식보다 위계."

## 2. 색

무엇을: 역할별 색 토큰과 쓰임. 왜: 컴포넌트 소스에 hex 리터럴 대신 역할 이름을 쓰게 하기 위해.

| 토큰 | 역할 | 예시 값 |
|---|---|---|
| `--color-bg` | 페이지 배경 | `#ffffff` |
| `--color-surface` | 카드·패널 배경 | `#f6f7f9` |
| `--color-text` | 본문 글자 | `#1a1d21` |
| `--color-text-muted` | 보조 글자(캡션·placeholder) | `#6b7280` |
| `--color-primary` | 주 행동(버튼·링크) | `#2563eb` |
| `--color-danger` | 파괴적 행동·오류 | `#dc2626` |
| `--color-border` | 구분선·입력 테두리 | `#e5e7eb` |

금지: 위 표에 없는 색을 소스에 쓰지 않는다. 새 색이 필요하면 계약 변경 사이클(R3).

## 3. 타이포그래피

무엇을: 폰트 패밀리와 크기 단계. 왜: 위계를 크기 단계 이름으로 고정해 임의 px를 막기 위해.

- 패밀리: `--font-sans`(예: `"Pretendard", system-ui, sans-serif`), `--font-mono`(예: `"JetBrains Mono", monospace`)
- 크기 단계(예시): `--text-xs` 12px · `--text-sm` 14px · `--text-base` 16px · `--text-lg` 18px · `--text-xl` 24px · `--text-2xl` 32px
- 굵기: 본문 400, 강조 600, 제목 700. 세 가지만 쓴다.
- 줄 높이: 본문 1.6, 제목 1.25.

## 4. 간격·크기

무엇을: 여백·패딩·간격의 단계. 왜: 4/8 배수 하나로 통일해 "대충 12px" 같은 임의값을 막기 위해.

- 기본 단위 4px. 단계(예시): `--space-1` 4px · `--space-2` 8px · `--space-3` 12px · `--space-4` 16px · `--space-6` 24px · `--space-8` 32px · `--space-12` 48px
- 컨테이너 최대 폭(예시): `--container-max` 1200px
- 반경(예시): `--radius-sm` 4px · `--radius-md` 8px · `--radius-full` 9999px
- 그림자(예시): `--shadow-sm`, `--shadow-md` 두 단계만.

## 5. 컴포넌트 규칙

무엇을: 반복 등장하는 컴포넌트의 고정 규칙. 왜: 같은 버튼이 화면마다 다르게 생기는 것을 막기 위해.

| 컴포넌트 | 규칙 (예시) |
|---|---|
| 버튼 | 높이 40px(`--space-10`), 패딩 좌우 `--space-4`, 반경 `--radius-md`. 주/보조/위험 3종만. |
| 입력 | 높이 40px, 테두리 `--color-border`, 포커스 시 `--color-primary` 2px 링. |
| 카드 | 배경 `--color-surface`, 패딩 `--space-6`, 반경 `--radius-md`, 그림자 `--shadow-sm`. |
| 표 | 행 높이 44px, 헤더 굵기 600, 구분선 `--color-border`. |

## 6. 레이아웃·반응형

무엇을: 브레이크포인트와 그리드. 왜: 화면마다 다른 기준으로 접히는 것을 막기 위해.

- 브레이크포인트(예시): `sm` 640px · `md` 768px · `lg` 1024px · `xl` 1280px
- 그리드(예시): 12컬럼, 거터 `--space-6`, 모바일에서는 1컬럼.

## 7. 상태·피드백

무엇을: 로딩·빈 상태·오류·성공의 표현. 왜: 상태 표현이 화면마다 제각각이면 사용자가 학습을 못 한다.

- 로딩: 스켈레톤(내용 자리) 우선, 스피너는 버튼 안에서만.
- 빈 상태: 아이콘 없이 한 문장 + 다음 행동 버튼 1개.
- 오류: `--color-danger` 텍스트 + 복구 행동. 모달로 띄우지 않는다.

## 8. 금지 사항

무엇을: 계약과 무관하게 항상 금지되는 것. 왜: 리뷰에서 바로 지적할 수 있게.

- 컴포넌트 소스의 색·크기·폰트 리터럴 (토큰만)
- 생성 툴 출력을 그대로 붙여 넣기
- 계약에 없는 폰트 패밀리·굵기 추가
- 이 파일을 화면 사이클 안에서 수정하기 (계약 변경은 별도 사이클)
